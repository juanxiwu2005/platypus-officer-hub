# 提醒计划、邮件和独立任务页：分阶段实施

2026-11-16（America/Phoenix）。基线 `claude/fervent-thompson-e2j5u2@dbfc47d`；开发分支 `feat/reminder-plan-v2`。Juanxi 已批准准备阶段和阶段一；阶段二、三仍待批准。

## 最新决定

- A：邮件只有一个核心任务入口；独立任务页办理与更新状态。
- 主题固定活动在前、项目在后；正文突出一个 Task due。活动日期只作为具体要求的背景；最晚开始日内置在计划里，触发时用“今天到了计划开始日期”解释，不再并排放三个日期。3 月 31 日截止、3 月 28 日提醒仅为用户例子；实际使用现有规则引擎 `latestStart`，不擅自一律减三个自然日。
- 默认完整提醒均由规则生成：收件人、活动/任务、日期、当前记录、具体要求、重要性、协作和感谢、唯一链接。AI 为后续可选且显式的润色，不阻塞预览、批准或发送，不决定日期/收件人/状态/链接；本轮不增加 AI 调用。
- Waiting on 必须自动创建对等待对象的独立跟进邮件事件：说明谁的哪项任务正在等对方、需要什么协助。事件遵循社团的三种发送方式：自动模式演示自动发送，两种审核模式进入待审；真正邮件服务仍属第六项。不能把自由文本猜成邮箱；对象未明确、已离任或为自己时保留待处理原因，不误投。
- Waiting on 不改变原任务负责人，不替等待对象创建递归任务，也不给等待对象修改原任务完成状态的权限。对象变化、任务完成、取消等待、重新分配后撤销旧待发跟进；发送历史保留。重复提交相同等待不重复发一封。

| 内容 | 生成方式 | 阶段 |
| --- | --- | --- |
| 收件人、活动、任务、人数、截止日、触发原因、逾期天数、链接 | 规则读取已保存事实 | 阶段一提供事实与候选 |
| 具体要求、完成标准和重要性 | 人工已有说明优先，已知步骤模板和真实依赖补充；缺失不造事实 | 阶段一提供基础说明，阶段二展示/编辑 |
| 问候、协作、感谢及整封排版 | 固定的自然语言规则模板 | 阶段二接入 |
| AI | 默认不调用；以后只有人工明确选择时可润色，失败不阻塞 | 当前不实施 |

阶段一的等待对象限于已明确选择的现任成员 Person；CRM 联系人或外部 ASU 审批人还没有显式收件人输入，不能把“等学校审批”等自由文本当邮箱。阶段二需要设计明确的外部联系人选择才能扩展此范围。

## 阶段一的确切边界

阶段一是底层和 reducer 可运行交付，不声称邮件样式、Details、新状态按钮或真实发送已经上线。可选 `reminderRuntime` 使用新版本运行时；旧 v22 存档没有它时原样保留，不自动重置、伪造发送、猜历史收件人或运行新旧双重催办。显式 `enableReminderPlan` 初始化以后才使用新路径。后续 UI 接入和统一激活在阶段三实施。

启用时关闭无法证明仍适用的旧 open silenceCase，已发生的领导通知和发送历史保留。未知版本或损坏的运行时原样保留但不执行，不以重置存档解决错误。旧邮件编辑器尚未改造，仍可能调用原有 AI；零 AI 的承诺针对本次新底层，不能称整个旧产品已停止 AI。

底层候选：开始日、截止日、逾期第 3 天。重合取更相关的一封；迟开系统只取当前最相关候选，不集中补发。同一任务、同一负责人任期、同一收件人最多三封，每人滚动七个自然日最多六封；等待对象的独立跟进不占原负责人的催办额度，但计入等待对象自己的额度。同日同一任务同一收件人最多一封。改期不重置同一任期限额。实际演示发送时间为操作当天，不倒填计划日期。既有自定义设置原样保留，阶段三设置迁移必须明确展示，不悄悄覆盖。

状态：Working on it 停止尚未开始提醒、仍可到期检查；Waiting on 暂停原负责人的普通提醒并生成对明确等待对象的跟进；Stuck 暂停普通催办且沿用现有求助通知；Done 停止候选但保留历史。改期重新算未来候选；换人新任期单独判断，历史收件人不变。新版已启用时旧 3/5 天成员催办不重复运行；领导跟进仍用原权限，并随完成/已回复/改期关闭或重建旧 case。

## 检查与交付

- 不依赖 AI 的事实/要求生成；缺人数不编造 40 人；未知入口不捏造链接。
- 同日更新、标题编辑、重新分配、改期、重开、完成、次数上限、审核/自动方式和持久历史都有实质测试。
- Waiting on 自动生成、同对象去重、换对象取消、完成后停止、自由文本未知对象、离任与自指拒绝；等待对象没有原任务修改权限。
- 验证显式启用与旧存档兼容；旧有相关测试、lint、前后端类型及构建。阶段一不为未改 UI 跑全站浏览器测试，不调用真实 AIR。
- 独立 Review 后提供提交、测试数字、场景输出与下一阶段边界。只推本任务功能分支，不合并 main、不发布正式网站。
