## 数据与兼容

实际 Node 新增可选 `externalLinks` 与 `taskWork`；外层仍为schema23，原字段和归档保留。未设置链接时使用现有已知平台入口，校园订房显示3个入口；校外场地不自动放入校园订房链接。明确设置空链接列表则保持为空，其他自定义节点可自行配置。没有声称入口页就是已登录后的具体申请表。

`taskWork`版本1：递增revision、按作者保存的drafts、追加submissions、去重files。提交记录保留正文、作者、演示业务日期、负责人任期和文件引用；实际操作时间仍在原交互日志。文件原始字节以下载专用base64数据与业务快照一起保存，因此刷新、完整业务导出/恢复可带回正文与附件。`saveTaskWork`业务日志仅记正文长度与附件元数据，不复制文件字节；原有UI输入日志沿用全站规则。AI上下文不自动包含提交或附件，旧draftLink仍提供打开入口。

浏览器原型限制为每次最多5个附件、每个512KB、每个任务含保存版本合计2MB；支持PDF、Office文档、文本和PNG/JPG/WebP图片。上传处理不自动执行或解析文件，点击附件以下载方式读取。读文件失败、保存失败或额度不足时保留当前文本和已选附件，不报告成功。异步读文件和提交之间重新核对归属、权限、内容版本及浏览器持久化，另一标签页的新副本不会被覆盖。不认识或损坏的taskWork保留且暂停编辑。

负责人邮件入口使用已保存且验证过的owner grant；写入作者取自grant，不能借用浏览器当前社长身份。waiting grant只允许回应协助，不可提交或完成原任务；旧一次性入口在真正提交后才消费。改派、离职或过期后撤销原入口。

正文作为通用自由文本保存，不自动抽取房号或改写活动地点字段。团队在对应节点查看同一份已提交结果。当前仍是同一演示浏览器的数据，不等于服务器跨设备共享、真实登录或外部邮件服务；没有新增真实AI调用。
