## Historical work and evidence

Preserve these files in their existing locations so links and implementation references remain usable. A translated report does not reapprove its plan or rerun its tests.

- `design-upgrade/`: interface/motion plans, work packages, reports, and rollback history.
- `onboarding-redesign/`: staged onboarding decisions, implementation reports, and rollback history.
- `release-readiness/`: release work packages and recorded verification.
- `phase1/`: earlier AI-native prototype architecture and handoff.
- `night-tasks/`, [Night Mode runbook](NIGHT_MODE.md), and [task template](NIGHT_MODE_TASK_TEMPLATE.md): paused automation and its known issues.
- [Historical agent notes](history/AGENT_HISTORY.md): an English index of prior instructions and implementation snapshots. Current `AGENTS.md` and later owner decisions take precedence.

The preview branch also contains `feedback-fix/`, `reminders/`, and `prototypes/` material that is absent from the production baseline. Use the index from the branch you are reviewing. Binary screenshots preserve their original pixels and may show historical language.
