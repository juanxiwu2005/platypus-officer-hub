# Goal

用 1–3 句话说明这次唯一要完成的用户结果。

# Files

- 允许修改的页面、组件、源文件或测试目录。
- 如果不知道文件名，写清楚允许涉及的功能区域。

# Constraints

- 只使用虚构演示数据。
- 不修改依赖、部署、GitHub Actions、密钥、研究数据或 Night Mode 安全文件。
- 不修改或合并 `main`。
- 保留现有产品规则、权限、日期引擎和人工确认闸门。
- 不在这里粘贴任何 API key、参与者信息或真实成员数据。

# Done means

- 用户在界面上能看到或完成什么。
- 哪些边界情况必须工作。
- 应新增或更新哪些单元测试和 Playwright 测试。
- `npm run check` 必须通过。

# Out of scope

- 明确列出这次不做的相邻功能，防止 Agent 擅自扩大范围。
