## Watch where you're going.
- The **test captures two real problems**:1 I assume that the Done column is empty, but in the demo data it has a card and the test is miswritten and changed to "take the first folding column"; 2 There is no style for folding switches on a mobile phone, which became an extra button and was caught by accessibility checks and is now `display: none` on the cell phone.
- **Known Limits (for DX-24)**: Every time a card is dragged across several empty columns, it spreads (the next column is squeezed) and the position jumps slightly. I do not "plug all folding columns while dragging" because it makes Playwright's `dragTo` count the wrong column (which currently depends on it). DX-24 replaces the browser with a pointer event.
- Minimum column width 120 px: When all six columns have jobs, the 1440 wide right bar can also be opened (approximately 100 ppx wide), but it will be narrower; This is the trade-off between "all visible" and "card width".
