# 报告：DX-21 看板列头减饱和

- 分支：`design/dx-21-board-headers`　执行：Claude，2026-11-01　回滚：R1（注释 `index.css` 里 DX-21 一行）或 R2；撤 DX-16 前要先撤它

## 做了什么
- `src/styles/dx-21-board-headers.css`：看板列头不再是整条饱和色块：背景透明、名字用正常文字色、前面一个 10px 的圆点（颜色就是 Settings → Board 里设的那个 `--pill`）、数字放在一个安静的小徽标里。**深色模式**下圆点加一圈浅色细环。`StatusPill`（表格、卡片、详情里的状态色块）**完全没动**。
- 折叠的竖条（DX-16）里圆点在最上面，竖排的名字在下面。

## 证据
- 对比度（圆点颜色 vs 列背景）：**浅色**下 10 个调色板颜色最低 4.19:1（To do #3a6fd8）；**深色**下 10 个里有 7 个低于 3:1（Not claimed 2.74、Stuck 2.90、Done 2.99、teal 2.82、magenta 2.79、olive 2.95、slate 2.12），所以深色加环。（计算用 WCAG 公式，列背景 #f3f1ec / #1d2322。）
- 新测试 `e2e/dx-21-headers.spec.ts`（电脑，5 个）：列头背景透明、名字是正常文字色、圆点 10px 圆形且颜色等于该列的状态色、旧的半透明白徽标没了；六个默认颜色在浅色下都 ≥3:1；深色下确实有 <3:1 的颜色且每个圆点都有环；浅色没有环；表格里的 `.pill` 仍是白字实心色块。
- 加 `tasks`、`a11y`（含自动对比度检查）、`dx-16-board`（桌面 + 手机）：**96 通过 / 14 按设计跳过 / 0 失败**。
- **反向验证**：清空本包样式，2 个测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 4 交接。

## 要注意的地方
- **没做 Stuck 的特殊处理**（说明书写"Stuck 保持一点警示"）：它需要给列加一个稳定的状态标记，而 `Tasks.tsx` 不在这个包的文件范围内；用状态名匹配会在用户改名后失效。需要的话在 DX-24（它会动 `Tasks.tsx`）里一并加。
- 用户自己选的颜色没有深色版本，所以深色的环是兜底，不是对每种颜色的精调。
