# 报告：DX-23 半透明顶栏 + 阴影层级 token

- 分支：`design/dx-23-glass-topbar`　执行：Claude，2026-11-01　回滚：R1（注释 `index.css` 里 DX-23 一行；但 `TopBar.tsx` 里的滚动状态会留着，无害）或 R2

## 做了什么
- `TopBar.tsx`：给 `<header>` 加 `data-scrolled`（页面滚动超过 0 就是 true）。
- `src/styles/dx-23-glass-topbar.css`：顶栏背景 = 80% 的页面底色 + `backdrop-filter: blur(16px) saturate(1.4)`，页面从下面滚过时透出来；底部那条线**滚动之后才出现**。三档阴影 token `--elev-1/2/3`（深色下更重，只用 `rgb(0 0 0 / x)`，没有 hex），换到 `.menu`、`.m-menu`、`.owner-suggest`、`.panel`、`.toast`、浮层状态的 `.rail`。**不模糊**菜单、悬停卡、详情面板和内容卡片（半透明叠半透明会看不清字）。回退成实心：浏览器不支持 `backdrop-filter`、系统开了"降低透明度"、系统开了"增强对比度"（后者还给一条明显的线）。

## 证据
- 新测试 `e2e/dx-23-glass.spec.ts`（电脑，6 个）：顶栏背景不透明度在 0.6–1 之间且 `backdrop-filter` 含 `blur(16px)`；页面里塞一块 3000px 高的东西后：顶部时 `data-scrolled="false"`、线完全透明，滚到 400px 后变 true、线可见，滚回去又消失；"增强对比度"下背景完全不透明、没有模糊、有线；三档阴影 token 存在、Demo 菜单的阴影用的是 `--elev-2`（浅色 `rgba(0,0,0,.1)`，深色 `.45`）。
- **反向验证**：清空本包样式，6 个里 5 个变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 5 交接。

## 要注意的地方
- **"降低透明度"这一条没法在这个浏览器里真的打开**：Playwright 自带的 Chromium 不认 `prefers-reduced-transparency`，所以测试改成"读规则本身"（检查样式表里确有该媒体查询、`.topbar` 变实心、`backdrop-filter: none`），浏览器认的时候才检查数值。`more contrast` 是真的打开验证的。
- 没有给 20b 的底栏做材质（20b 没做）。
- 深色下"模糊后的文字对比度"我没有单独测：顶栏文字是 `--ink`，底下是 80% 的 `--surface` 加 20% 滚过来的内容；`a11y.spec.ts`（含自动对比度）在合并后的完整检查里覆盖。
