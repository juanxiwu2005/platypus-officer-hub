## Minor incident (for future maintainers)
Initially `useToast` used `return [toast && <div/>, setToast]`, flagged by `react-x/no-missing-key` as an array element missing a key. Fixed by assigning the node to a variable before returning. Future `Toast.tsx` work (DX-11) should not put JSX directly in an array literal.
