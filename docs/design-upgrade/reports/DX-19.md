# 报告：DX-19 详情切换交叉淡入 + 页面淡入

- 分支：`design/dx-19-detail-swap`　执行：Claude，2026-11-01　回滚：R2（依赖 DX-09）

## 做了什么
- `src/styles/dx-19-detail-swap.css`：右栏 Details 里换成另一个任务/步骤/联系人时，新内容从透明淡入（`--dur-fast`，只动透明度，不动布局、滚动、焦点）；页面切换时 `main` 的直接子元素淡入。"减少动效"下都不动。
- `src/components/Layout.tsx`：路由变化时，用 `useLayoutEffect`（在新页面**绘制之前**）给 `<main>` 加一个临时类 `route-enter`，淡入结束后摘掉。所以页面里之后才出现的东西（展开的卡片、加载完的列表）不会跟着淡入；第一次加载页面也没有；**没有退场动画、没有滑动**（不会让导航变慢）。`#main`、`tabIndex`、焦点管理、换页时收起右栏的逻辑都没动。

## 证据
- 新测试 `e2e/dx-19-swap.spec.ts`（桌面，4 个）：首次加载 `main` 没有 `route-enter`；点侧边导航换页时逐帧看到内容淡入、位移始终为 0、结束后类被摘掉；在 Tasks 里切换 Board/Table（页面内部变化）不触发淡入；在 Today 点另一个任务，Details 里的新内容淡入，再点同一个任务不会重播；"减少动效"下没有淡入动画。
- 回归（桌面 + 手机）：`smoke`、`today`、`tasks`、`events`、`a11y`、`recovery`、`touch`：**160 通过 / 9 按设计跳过 / 0 失败**。
- **反向验证**：清空本包样式，2 个测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 3 交接。
