# 报告：DX-12 手机悬停卡底部弹层动画

- 分支：`design/dx-12-touch-hover-sheet`　执行：Claude，2026-11-01　回滚：R1 或 R2

## 做了什么
- `src/styles/dx-12-touch-hover-sheet.css`，只在 `@media (hover: none)`：悬停卡一直是屏幕底部的固定面板，只是隐藏时在下方 12px 且透明；点开时滑上来并淡入，关闭时滑下去并淡出（`--dur-fast`，`visibility` 在淡出结束后才隐藏）。没有遮罩。**桌面不变**：`.hover-card` 仍然零延迟（S3，`feel.spec.ts` 守着）。没有改 `Hover` 组件。

## 证据
- 新测试 `e2e/dx-12-sheet.spec.ts`（手机，2 个）：点开时逐帧看到淡入和上滑（0–12px），最终 `opacity 1、y 0、visible、fixed`；点别处后淡出期间仍可见，最终 `opacity 0、hidden`；"减少动效"下直接出现/消失。
- 加 `touch`、`feel`（桌面悬停卡仍零延迟）、`bts`（桌面 + 手机）：30 通过 / 6 按设计跳过 / 0 失败。
- **反向验证**：清空本包样式，动效测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 2 交接。

## 要注意的地方
- 关闭状态的卡片现在也是 `position: fixed`（隐藏着，不占位）；如果某个祖先元素有 `contain: paint`，它会相对那个祖先定位，但隐藏时看不见，打开时的行为和以前一样。
