# 报告：DX-04 触屏点击区 ≥44px

- 分支：`design/dx-04-touch-targets`　执行：Claude，2026-11-01　回滚：R1 或 R2

## 做了什么
- `src/styles/dx-04-touch-targets.css`，全部包在 `@media (pointer: coarse)` 里，桌面不变：`.btn`、`.chip`、`.icon-btn`、分段按钮、右栏标签、导航、`select` 和文本输入最小高度 44px（`.icon-btn` 宽度也是 44px）；表格、卡片、菜单里的小控件至少 32px；`.swatch`、`.info`、`.chain-btn`、流程图圆点、风险点保持原有外观，只把看不见的点击区扩到约 32px；"Open" 这类小文字链接用 `padding` 加负 `margin` 变高但不撑动版面。

## 证据
- 新测试 `e2e/dx-04-targets.spec.ts`（只在手机项目跑）：Today、Events、Tasks、Team、Partners、Rules、Handoff 七页，所有主要控件高度 ≥44px，所有能点的东西"自身或点击区"≥32px；另有一条确认手机确实匹配 `(pointer: coarse)`。
- 手机项目：新测试 + `a11y` + `touch` + `word-budgets` 共 46 通过；`events` + `flow-edit` 26 通过；0 失败。
- `npm run lint`（含样式守卫）通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 1 交接。

## 要注意的地方
**测试抓到两个问题**：① 我给 `.btn.small` 加的最小宽度压过了 `.icon-btn` 的 44px 宽度，改成 `.btn.small:not(.icon-btn)`。② 流程图圆点的点击区原来是从圆环内侧算起的，实际只有 28px，改为 `inset: -6.5px` 才够 32px。
**没有验证**：真机手指点击的手感，只验证了尺寸。
