## 做了什么
- `src/components/ui/index.tsx`（只动 `Chain`、`Ring`）：`Chain` 记住上一次每个站的状态，**只有在同一个实例里从"没完成"变成"完成"的站**才带 `just-done` 一小会儿（弹簧时长 + 80ms）；第一次画、重新进入页面、本来就完成、往回撤销、"减少动效"都不触发。`Ring` 的圆弧加了类名供过渡使用。
- `src/components/chrome/SideNav.tsx`：Tasks 旁边的数字变化时弹一下（第一次画不弹）。
- `src/lib/motion.ts` 复用 DX-22 的（本分支里也带了同样的文件，合并时内容一致）。
- `src/styles/dx-25-done-moment.css`：完成的那一站，通向它的线从左向右"长出来"（`scaleX 0→1`），圆点用 `--spring-pop` 从 0.6 倍弹到 1；圆环数值变化时用 `--dur-slow` 过渡；Tasks 数字 1.25 倍弹一下；**进度链里"有风险"的圆点里面画一个感叹号**（小的 `compact` 链不画，点太小）。没有彩带、声音、震动、循环。

## 证据
- 新单元测试 `src/test/chainMoment.test.tsx`（7 个）：第一次画不显示；刚完成的那一站、且只有那一站被标记，一会儿后放手；同样的站重画不再标记；本来就完成或被撤销的不标记；多个站同时完成都标记；"减少动效"下不标记；新增的站不算"刚完成"。
- 新浏览器测试 `e2e/dx-25-done.spec.ts`（电脑 5 个）：样式——给一个站加上 `just-done`，线的缩放从 <0.5 长到 1、中间帧被看到、圆点从 <0.8 到 1 且最大不超过 1.05；没有该类时都没有动画；圆环把 `stroke-dasharray` 改掉后有中间值；**真实**把一个任务标为 Done，Tasks 导航的数字变化且第一次画时没有 `is-pop`；风险点有感叹号（小链没有）；"减少动效"下没有动画。
- **反向验证**：清空本包样式，5 个里 3 个变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 5 交接。
