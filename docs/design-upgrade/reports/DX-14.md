# 报告：DX-14 加载骨架 + 延迟显示

- 分支：`design/dx-14-loading-skeleton`　执行：Claude，2026-11-01　回滚：R1 或 R2

## 做了什么
- **和说明书不同的做法**：说明书写的是改 `RouteLoading.tsx`。我用纯 CSS，**没有改任何 `.tsx`**：前 150ms 什么都不显示（用 `animation-delay: var(--dur-fast)` 加 `backwards` 填充），之后用 `::before` 画出一个标题条加三张卡片条的灰色骨架并淡入；静止，不闪光。原来的 "Loading…" 文字留在页面里给读屏用，只是视觉隐藏。整页和右栏详情两种用法都生效。

## 证据
- 新测试 `e2e/dx-14-loading.spec.ts`：前 120ms 骨架透明度恒为 0（不闪），160ms 之后淡入，最终为 1；读屏文字仍在、视觉上被压成 ≤1px、占位高度 ≥320px；"减少动效"下很快出现。
- 加 `bundle-performance`、`bundle-organization-setup`（它们断言 "Loading workspace" 的 `main` 可见、状态文字是 "Opening your workspace…"、占位高度 ≥320、axe 无违规）、`a11y`（桌面 + 手机）：**77 通过 / 3 按设计跳过 / 0 失败**。
- **反向验证**：清空本包样式，2 个测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 2 交接。

## 要注意的地方
- 骨架的块是用背景渐变画的，没有圆角（渐变层不能单独圆角）。如果你想要圆角，需要在 `RouteLoading.tsx` 里加真实的元素，那是 R2 的做法。
