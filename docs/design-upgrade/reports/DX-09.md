# 报告：DX-09 右栏滑入滑出 + Ask 按钮 + 安全区 + dvh

- 分支：`design/dx-09-rail-motion`　执行：Claude，2026-11-01　回滚：R2（DX-19、DX-20 依赖它，先撤它们）

## 做了什么
- `Layout.tsx`：新增 `useRailPresence`，关闭时不立刻卸载，等动画走完再卸载；打开时先以"收起"的样子画一帧再进入（所以有东西可以过渡）。"减少动效"时完全不走这条路：开就是开，关就是关，立刻卸载。
- `Rail.tsx`：新增 `closing`、`shown` 两个属性。**关闭一开始（`closing`）就释放背景的 `inert`、移除点击外部/Escape 监听**，不等动画结束；`<aside>` 带 `data-state="open|closed"`。
- `src/styles/dx-09-rail-motion.css`：宽屏（≥1200px）淡入 + 位移 8px，页面列宽直接改变；窄屏（<1200px 浮层）从右边 `translateX(100%)` 滑入、原路滑回；`data-state="closed"` 同时代表"正在进来"和"正在出去"，所以中途改主意会从当前位置反向。`.ask-fab`：底部和右侧加安全区、按下缩小、出现时轻轻弹出。`.rail` 的高度改用 `100dvh`。

## 证据
- 新测试 `e2e/dx-09-rail.spec.ts`（7 个）：平板宽度下逐帧记录面板位移，从 >300px 单调降到 0，中间帧被看到，退出沿原路单调增加并最终被移除；关闭一开始 `#main`、导航、顶栏就没有 `inert`；中途掉头从当前位置反向（没有跳回 100% 或 0）并最终移除；宽屏淡入淡出、首次加载没有入场动画；"减少动效"下点开立刻存在、点关立刻消失；样式规则里确有 `env(safe-area-inset-bottom)` 和 `100dvh`；宽屏面板高度 = 900−56−28。
- **反向验证**：临时清空本包样式，3 个动效测试变红；安全区测试原版写得分不出新旧（桌面浏览器里数值相同），已改成检查样式规则本身，再重测通过。
- 回归（桌面 + 手机）：`smoke`、`today`、`tasks`、`events`、`touch`、`a11y`（含右栏焦点陷阱、`inert`、Escape、点外面关闭）、`m2b`、`feel`、`bts`、`recovery`、`crm`：**201 通过 / 7 按设计跳过 / 0 失败**。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 2 交接。

## 要注意的地方
- 宽屏关闭时，页面列在面板淡出结束后才变宽（面板保留到动画走完，所以 `with-rail` 类也保留到那时），大约晚 260ms；打开时是一开始就变窄。这是为了不在动画中途让网格错位。
- 说明书写的"Ask 圆按钮在打开右栏时淡出"没做：右栏滑入时会盖住它，单独做收益很小；只做了出现时的弹出和按下反馈。
- `RailContext.tsx` 没有改动。
