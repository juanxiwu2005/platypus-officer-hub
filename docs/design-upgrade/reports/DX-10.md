## 做了什么
- **和说明书不同的做法**：说明书写的是在 `DemoMenu.tsx`/`Bell.tsx` 里加 `data-state` 并延迟设 `hidden`。我改用纯 CSS（`@starting-style` 加 `transition-behavior: allow-discrete`），所以 **没有改任何 `.tsx`**：`hidden` 属性仍然是唯一开关，焦点、读屏、点外面关闭、Escape、"Reset 要点两次"的 3 秒超时全部原样。这也让它可以 R1 一行关掉。
- `src/styles/dx-10-menu-motion.css`：`.menu` 进入 = 淡入 + `scale(.96)→1` + 上移 4px（`--dur-fast`），退出更快（`--dur-press`）；退出期间 `display` 等淡出结束才变 `none`；`transform-origin` 在按钮一侧（右上），手机上的全宽菜单从中间长出。不支持这个写法的浏览器退回到瞬间切换。

## 证据
- 新测试 `e2e/dx-10-menu.spec.ts`（桌面，5 个）：Demo 菜单和铃铛菜单逐帧看到淡入（8 帧左右）和淡出，`hidden` 在渲染后几帧内变真、淡出期间仍可见、结束后 `display: none`；退出时长小于进入时长；点外面、Escape 仍能关；"减少动效"下直接出现/消失。
- **反向验证**：清空本包样式，3 个动效测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 2 交接。
