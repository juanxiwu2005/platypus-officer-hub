## Issue found and fixed after merge (integration check)
Full stage 2 check timed out in `recovery.spec.ts` (two-click Reset demo) and `dx-11-toast.spec.ts`, both green individually in their worktrees.
**Cause:** After Escape, menu fades before `display: none`; helper `openDemoMenu` used “Reset button visible” as open-state signal, misread the exit frame, did not reopen, and clicked a disappearing button. Real users unaffected (clicking trigger again opens it).
**Two fixes (commit `[DX-10][Claude] Fix…`):**① reduced motion uses `.menu { transition: none }`, hiding in the same frame with no wait; ② `openDemoMenu` in `e2e/helpers.ts` checks trigger `aria-expanded` (state, unaffected by animation), then waits for Reset visibility. **No weakened assertions.**
**Lesson:** Green in individual worktrees does not ensure green after merge; tests equating visibility with open state race against exit animations.
