# 报告：DX-13 折叠区展开动画

- 分支：`design/dx-13-details-motion`　执行：Claude，2026-11-01　回滚：R1 或 R2

## 做了什么
- `src/styles/dx-13-details-motion.css`：`@supports (selector(details::details-content))` 里，`details::details-content` 的 `block-size` 从 0 过渡到 `auto`（`interpolate-size: allow-keywords`，`--dur-base`）；不支持的浏览器保持原来的瞬间展开。**清点**：仓库里共有 37 处 `<details>`（`ChangeCard`、`NudgeComposer`、`OrgDetail`、`ContactDetail`、`FollowupPanel`、`SettingsForms`、`NodePanel`、`TaskDetail`、`Handoff`、`Setup`、`Funding` 等），全部自动生效，没有改任何 `.tsx`。

## 证据
- 新测试 `e2e/dx-13-details.spec.ts`：放进一个 160px 高的 `<details>`，打开时高度逐帧增长并看到中间值，关闭时逐帧缩回并回到原高；"减少动效"下没有中间值；一个应用里真实的折叠区（Events 流程图节点详情）仍能点开。加 `events`、`m2b`（桌面 + 手机）：**44 通过 / 0 失败**。
- **反向验证**：清空本包样式，动效测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 2 交接。

## 要注意的地方
- 这是整个升级里**唯一动画高度（布局属性）的地方**：展开一个折叠区没有别的平滑办法。样式守卫禁止的是 `height`、`width` 等物理属性，没有拦 `block-size`，我在样式文件的注释里写明了这是有意的例外。
- 没有给 `summary` 的箭头加旋转：浏览器自带的三角形不能旋转，仓库里也没有统一的自绘箭头。
