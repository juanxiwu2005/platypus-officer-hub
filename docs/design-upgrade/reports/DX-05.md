# 报告：DX-05 风险点加形状

- 分支：`design/dx-05-risk-shapes`　执行：Claude，2026-11-01　回滚：R2（DX-25 依赖它，先撤 DX-25）

## 做了什么
- `src/components/ui/index.tsx` 的 `RiskDot`：每种状态一个形状（On track = 圆里一个对勾，Watch = 三角里一个感叹号，At risk = 圆角方块里一个叉），内联 SVG，颜色来自原来的 `--good`、`--risk-yellow`、`--late`；尺寸 11px → 14px；原有的 class、`data-testid="forecast"`、`aria-label`、`withWord` 都保留；没有新增文字。
- `src/styles/dx-05-risk-shapes.css`：去掉旧的色块底和光晕，图案用页面底色描边。

## 证据
- 新测试 `e2e/dx-05-shapes.spec.ts`：Today 上出现的不同状态各画出不同的形状；深色下图案颜色与形状颜色不同。
- `dx-05`、`today`、`wp5`、`a11y`、`events`、`touch`（桌面 + 手机）：125 通过 / 5 按设计跳过 / 0 失败（含 axe 无障碍）。
- 灰度检查：把三种形状转成灰度图，仍然一眼能分出圆、三角、方块。
- 形状对页面底色的对比度（图形要求 ≥3:1）：浅色 5.21 / 3.31 / 6.57，深色 9.00 / 7.63 / 7.10（On track / Watch / At risk）。
- `npm run lint`（含样式守卫）通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 1 交接。

## 要注意的地方
**灰度图抓到一个真问题**：旧样式 `.risk.red i` 的色块底和光晕优先级更高，没被覆盖，形状外面多了一圈方框。改用 `.risk:is(.green, .yellow, .red) i`（同优先级、更晚加载）后干净。
`Chain`（进度链）里"有风险"的点仍然只靠红圈，按计划在 DX-25 里处理。

## 截图证据
合并后桌面 Today 风险点由圆点变成三种形状，标题字距变化来自 DX-06；肉眼检查浅色和深色的 Today，没有错位。
