# 报告：DX-17 Ask 面板：空状态居中、新消息进入

- 分支：`design/dx-17-ask-panel`　执行：Claude，2026-11-01　回滚：R2

## 做了什么
- `src/components/rail/AskPanel.tsx`：还没有消息时，问候语和建议问题（原来在面板底部的那一排）成组放在对话区正中（`ask-welcome`）；发出第一条消息后，建议问题回到面板底部的老位置。**同一排建议问题永远只渲染一份**。面板打开时已有的消息不动画，之后新增的才带 `is-new`（用"打开时就有哪些 id"判断，面板重新打开不会重播）。**没有任何新文案**。
- `src/styles/dx-17-ask-panel.css`：欢迎组垂直居中；新气泡和 "Platypus is working" 卡片 6px 上升 + 淡入（`--dur-fast`）；"减少动效"下不动。

## 证据
- 新测试 `e2e/dx-17-ask.spec.ts`（桌面，4 个）：欢迎组离空闲区域正中 <60px、只有一排建议问题；发消息时逐帧看到新气泡淡入和上升（0–6px），欢迎组消失，建议问题移到底部；面板真正关闭再打开后没有任何 `is-new`；"减少动效"下没有动画。
- 回归（桌面 + 手机）：`m2b`、`today`、`smoke`、`a11y`、`touch`、`wp5`：**138 通过 / 9 按设计跳过 / 0 失败**。
- **反向验证**：清空本包样式，2 个测试变红。
- `npm run lint`（含样式守卫）和类型检查通过；阶段合并后的完整 `npm run check` 结果见 `docs/PROGRESS.md` 的阶段 3 交接。

## 要注意的地方
- 一开始"重新打开不重播"的测试写错了：点"收起"后立刻点"打开"，动效模式下面板还在退场、没有卸载，是同一个面板实例，旧气泡的 `is-new` 类还在（类不变，动画不会重播，但测试数的是类）。改成先等面板真的卸载。
- 手机项目只靠回归测试覆盖（本包新测试都用桌面的停靠面板）。
