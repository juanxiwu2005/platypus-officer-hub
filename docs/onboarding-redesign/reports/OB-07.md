## Changes

Completed three member screens (flow B screens 0–2), replacing OB-01 placeholders:

- **Invitation**: Demo strip "Previewing as Maya Chen · Change"; large organization-name heading; "Alex Rivera invited you to be **Treasurer**"; enlarged role card (role, Reports to, duties max 3 lines); three benefits; one trust statement; bottom-aligned Continue.
- **Invalid invitation**: `?invite=` differing from browser's invite code, unknown `?person=`, or no organization members shows `copy.invalidInvite`, one Demo note, two next actions ("Use this browser's invitation" returns to a valid invite; "Go to Today"). Missing `?invite=` means this browser's invitation and displays directly.
- **You**: editable name/email prefilled from officer. Continue uses `validateProfile` (nonempty name, example.org email) plus Settings' no-duplicate-name check; errors have `role="alert"`. "Not you?" opens/focuses top Change selector. Only this screen adds "Fictional demo. Choosing a name does not verify an identity." once to Demo strip.
- **Reminders**: three full-row native-radio choices (WhatsApp/SMS/Email, ≥44px). **Phone appears only for WhatsApp/SMS**, with `phoneWhy`; existing `validateProfile` phone rules (optional, 555-01xx); **no ASU ID**. Morning/Evening segmented choice, quiet-hours sentence, dynamic example bubble (WhatsApp green rounded with tail, SMS gray/right, Email card/left border; “this morning / this evening” follows time). Marked "Example", display-only, no sending. Required, no Skip.
- Motion: no selection displacement; bubble changes fade by opacity only,`--dur-fast`; repeated click restarts immediately without queuing; reduced-motion token 1ms gives direct switch.
- Primary action bar `position: sticky`, bottom of viewport even on short pages; only this bar blurs, solid fallback under reduced transparency/no support. Mobile Continue full-width, Back left.
- Change selector: small Demo-strip `<select>` lists all officers ("Maya Chen · Treasurer"), defaults first non-president. Escape/blur closes, returning focus to Change.
