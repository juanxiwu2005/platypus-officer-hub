# OB-09 确认 + 邀请 + 社长流程接社员预览

分支：`design/ob-09-confirm-invite`（本地，未推送）。执行者：Claude。

## 做了什么

- **Confirm（第 6 屏）**：一句话总结 "This creates {club} with {n} officers and {event} on {date}."（官员数 = `draft.club.people` 里有名字的人；日期是用户确认过的 `draft.date`，只做 `fmtLong` 格式化）。两个按钮 **Start workspace** / **Keep current demo**，加一个小的 Back。
  - Start：先 `validateClub`，不通过显示 `role="alert"`；再检查 event / 日期（保险）；然后 `dispatch({ type: "completeSetup", … })`，参数和 `Setup.tsx` 末尾完全一致（`fillEmails`、`inviteCode`、`clubBufferBusinessDays: draft.buffer`、`workflow: draft.steps`）→ `draft.clear()` → `navigate("/welcome/founder/invite")`。用 `useRef` 挡住连点和 StrictMode 重复。
  - 替换警告只在 `state.org.setupCompletedOn !== null` 时显示，普通文字，在按钮上方。
  - Keep current demo 走 `flow.exit()`（等于 `recordEvent(exit)` + `endWalkthrough("exited")` + `navigate("/")`），不动任何数据。
  - 没有可用事件/日期（比如直接打开这个网址）：显示 "Plan your first event before you start."，主按钮换成 "Back to first event"（没有 Start）。
- **Invite（第 7 屏）**：标题 + 三个按钮 Copy link / WhatsApp / Email；权限说明与 notSent 各一句；只读链接框（Copy 失败时选中它并提示 "Press Ctrl+C to copy."）；官员列表 = `state.roles` 里除社长外每个岗位一行（姓名 + 岗位；没有名字的显示 Open position、无状态；状态 Invited / Joined，Joined = 该 person 的 `setupCompletedOn` 非空；旁边一个 Info 说明这是同浏览器演示）；主按钮 **See what your officers will see** → `/welcome/member/invitation`，次按钮 **Go to Today** → `endWalkthrough("completed")` + `/`。没有 Back、没有 App 外壳，没调用 `next()`。
  - 链接与 Settings 的 `InviteLink` 同一写法。WhatsApp = `https://wa.me/?text=…`，Email = `mailto:?subject=…&body=…`，预写消息是一句英文，含社团名和链接，不含任何官员联系方式；都是 `target="_blank" rel="noopener noreferrer"` 的普通链接，不发网络请求。
  - 点 See what your officers will see 时只记录 founder.invite 的 leave 和 member.invitation 的 enter，**不结束尝试**，同一个 attempt 继续记录到社员屏。Joined 出现时只做 opacity 淡入（`--dur-base`，减少动效时 token 为 1ms）。
- 文案：只改 `copy.ts` 的 `founder.confirm`、`founder.invite` 两个区块（加了 key；`notSent`、`permission` 缩短了一点以守 60 词）。
- 新增文件：`founder/confirm/summary.ts`、`founder/invite/links.ts`（纯函数）、样式 `ob-09-confirm-invite.css`。

## 怎么验收（点哪里）

1. 打开 `/?walkthrough=1#/welcome/start`（Start walkthrough 目前仍去旧设立页，所以用这个入口开始记录），然后把网址改成 `/#/welcome/founder/name`。
2. Name 填社团名 → Continue；Constitution、Goals、Team 各点 Skip；First event 点 "Welcome mixer"、Plan it、Continue → Confirm。看一句话总结，点 **Start workspace** → Invite。
3. 在 Invite 看三个按钮、官员列表（都是 Invited）；点 Copy link 出现 Copied；点 **See what your officers will see** 走社员预览 6 屏到 Done；回到 `/#/welcome/founder/invite` 那位官员变 Joined；Done 点 Open my tasks。
4. 再来一遍（已设立过）：Confirm 上方出现 "This replaces the current demo workspace."，点 Keep current demo 回 Today，数据不变。

- 没跑完整 `npm run check`、`npm run words`。

## 遇到的问题 / 需要整合人决定

1. **`draft.clear()` 有竞态（draft.tsx，不是我的文件）**：草稿在最后一次改动 700ms 后自动保存；如果用户在那之前点了 Start，已排队的保存会在 `clear()` 之后把草稿写回 IndexedDB（e2e 复现到了）。我在 Confirm 里只做了绕过：`clear()` 之后 800ms 再 `clear()` 一次。更好的修法是 `draft.tsx` 的 `clear` 同时取消待保存的定时器——建议整合人处理。
2. Start walkthrough 目前仍去旧设立页（阶段 3 切换），e2e 因此用 `/welcome/start` 开始记录再改 hash。
3. Confirm 在没有可用事件时没有自动跳回 first-event，而是显示提示和 "Back to first event" 按钮（自动跳会让提示一闪而过）。前一屏已拦住这种情况，这里只是保险。
4. Info 的悬浮文字（Joined 说明）不计入"一眼看到"的字数；Invite 实测不含姓名的可见字数在 60 以内（e2e 断言）。
5. 已知脆弱旧测试：`src/test/engine.test.ts` 的 "no change ever makes a step start after its own club deadline" 在整套 `npm test` 里超 5 秒失败（924 通过 / 1 失败），加 `--testTimeout=30000` 单独重跑通过，未改。
