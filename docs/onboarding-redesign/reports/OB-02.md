# OB-02 · 本机 onboarding 记录

## 做了什么

- 新增独立的 `platypus.v1.onboarding` 浏览器记录，只保存入口、版本、屏幕事件、时间和完成结果；不保存表单内容。
- 导出数据新增 `onboarding` 顶层字段；Reset demo 仅重新亮起入口，不删除记录。
- 存储不可用时所有记录函数安全退化，不抛异常。

## 怎么验收

阶段 1 的入口完成后，走一次 walkthrough，再在 Settings 导出数据，确认 `onboarding` 存在且没有填写内容。

## 测试

Node 22：`npm test -- --run src/test/onboardingRecord.test.ts src/test/safety-storage.test.tsx`（18 通过）；`npm run lint`、`npm run build` 通过。

## 没验证的

真机手指、Safari，以及尚未由 OB-03 接线的完整浏览器流程。

## 回滚

撤销本包的合并提交即可；它只增加独立存储键和导出字段。
