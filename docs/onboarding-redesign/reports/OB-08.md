# OB-08 社员预览后半：Busy weeks + About you + Done

分支：`design/ob-08-member-finish`（本地，未推送）。执行者：Claude。

## 做了什么

- **Busy weeks（第 3 屏，可跳过）**：从 `state.today` 所在周起 18 周，按月分组的 44px 方块。点一下选中/取消（`aria-pressed`、勾号、键盘 Space/Enter 可用）。期末周用斜纹、假期/春秋假/学期之间用虚线，读屏名字里带 "finals week, already avoided" 等；这些周也能点。数据全部来自 `engine/calendar.ts`（FINALS / BREAKS / TERMS / HOLIDAYS）。存的每一项都是周一（`mondayOf`），最多 20 周（满了其余方块禁用并提示）。底部 "Skip — nothing busy yet"。
- **About you（第 4 屏，可跳过）**：职业目标、兴趣、期望三个问题一屏；每题 3 个建议小标签（点一下填入，已有内容就用逗号追加，不重复），也可打字；超过 500 字符显示 `role="alert"` 并拦住 Continue（不存超长内容）。Skip for now + skipHint。
- **Done（第 5 屏，必填）**："You're in."；组织图（复用 `OrgChart`）里该干部的节点出现一次（opacity + scale，`--dur-slow`，减少动效下 token 为 1ms，只剩高亮边框）；"Your first task" 卡：该干部 ownerId、未 done、按社团截止日最早的节点，日期来自 `node.clubDeadline`（只做显示格式化）；没有就显示 `empty` 加一行 Tasks 预览说明。**Open my tasks**：记录 `complete` → `endWalkthrough("completed")` → `navigate("/tasks")`，不改 viewerId。
- **保存**：进入 Done 时（`useRef` 防重复）把 OB-07 的暂存（`readChoice` + `previewPatch`）与 extra 合并，先用 `validateProfile` + 重名检查（`previewProblem`），通过才 `dispatch({ type: "saveProfile", personId, patch, invite: state.org.inviteCode })`，然后清掉两个暂存 key。不通过就不保存，屏上 `role="alert"` 写原因，暂存保留，出现 Back 按钮可回去改。`asuId` 永远是空字符串；个人缓冲、空闲时段等沿用 `profilePatch(person)`。直接打开 Done（没有暂存）不保存。
- 动效：toggle 周、点标签只改颜色，不位移；Done 的节点出现是整个 member 流程唯一的演出。

## 新的暂存 key

`sessionStorage["platypus.v1.onboarding.member.extra"]` = `{ v:1, personId, busyWeeks?, careerGoal?, interests?, expectations? }`。比任务里写的多一个 `personId`（防止换了干部后把别人的忙碌周套到新干部上）；读取时多余/超长/非日期的内容会被丢掉（`finish/extra.ts`）。Skip 会删掉该屏对应的字段（表示"不改"，Done 就沿用干部原来的值）。

## 怎么验收（点哪里）

1. 先打开任意页面让样例社团生成，再开 `/#/welcome/member/invitation` → Continue 三次到 `/#/welcome/member/busy-weeks`（也可直接打开这个地址）。
2. 点几周（12 月 7 日那周是斜纹，读屏说 finals week）；Continue → `/#/welcome/member/about`，点标签、打字、粘 501 字符看报错；Continue → `/#/welcome/member/done`。
3. Done 看组织图里 Treasurer 高亮、第一件事（Reconcile September receipts，Mon, Oct 26）；去 Settings 看 Maya 的资料已保存；点 **Open my tasks** 到 `/#/tasks`。

## 遇到的问题

1. worktree 起点是旧提交，按指示 `git reset --hard claude/determined-johnson-yrdxwf` 后改名分支。
2. 样例干部已有忙碌周/职业目标等（Maya 有 2026-11-09、"Corporate finance"），所以 Busy weeks 默认已选中她原来的周，About 的输入框有预填；"点标签追加"会接在原内容后面。测试已按此写。
3. `saveProfile` 在重名时会静默返回原状态，所以 Done 在 dispatch 前自己检查重名（`previewProblem`），不会"以为保存了其实没有"。
4. Busy weeks 为了守 40 词，方块里不写日期，只在月份标题下排布；每格的 `title` 和读屏名字是 "Week of Oct 19"。如果整合人希望每格看得到日期，字数会超过 40，需要决定。
5. About 的字数实测 39（接近 40 的上限，含共用的 skipHint 7 个词）。
6. 已知脆弱旧测试：`src/test/engine.test.ts` 的 "no change ever makes a step start after its own club deadline" 整套 `npm test` 里超 5 秒失败（883 通过 / 1 失败），未改。
