## Tradeoffs/limits for integrator

1. **Module singleton background reading**, not component state, so continues after leaving. Writes through stable provider `draft.update` supplied on Constitution mount; each write checks same `draft.doc.checksum`, avoiding cross-document contamination. Limits:
   - Save & exit unmounts provider; React ignores writes, task ends without retention.
   - Refresh loses in-flight reading; draft retains document/applied roles, not `reading`, same as old page.
   - Must visit Constitution to start, ensuring `update` is attached.
2. **Skip cancels reading/clears `draft.doc`**: document not retained after selecting then skipping.
3. **Failure reason hidden:** old page showed "(HTTP 404)"/"Your Netlify login expired"; strategy Section 6 requires generic new copy. Expired preview login now also shows generic fallback; cost of hiding reason.
4. Visible text slightly differs: "Read in your browser. AI finds roles; the text is not stored." (≤40 words); full "text is sent to AI to find roles and is not stored" in adjacent Info. No storage means AI server, while browser retains existing `saveLocalDoc` copy (Info explains).
5. `clubDraft(state)` defaults demo club name, so Continue initially enabled; disabled only after clearing, unchanged OB-01 behavior.
6. After prior application, new document resets `draft.applied` false so new results apply again, matching old `startReading`.
