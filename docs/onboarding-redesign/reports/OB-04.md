## Distinguished and Restricted (please integrater know)

1. **Backstage Reading Single Example**, which is not the state of the Constitution component: this way the user leaves this screen and the task continues. Writes to `draft.update` (provider provided, citation stable) when mounted through the Constitution screen. Checks if `draft.doc.checksum` is still the same document every time you write, so no other draft document will be written. Limits:
   - After the point Save & exit (provider unmounting), the job writing is ignored by React and the task ends naturally and is not retained.
   - The whole page is updated to lose an ongoing reading (retention of the document and applied role in the draft, but `reading` does not exist and is consistent with the old pages).
   - It must be started once (only this screen can start reading), so there is no case of without `update`.
2. **Skip will cancel reading and clear `draft.doc`**. If the user selects the document and then points to Skip, the document is not retained.
3. **failed without showing the reason**: Old pages will write "(HTTP 404)" or "Your Netlify login is expired". Section 6 shows new text only by strategy. When the preview site login expired, users would only see it and walk through the browser version, at the cost of removing the cause.
